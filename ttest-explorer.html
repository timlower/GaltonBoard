Comparison

★Why pairing helps

The paired test works on the difference scores, whose variance shrinks as the correlation between conditions grows:

Raise the correlation r and the paired standard error falls while the independent one stays put. Set r near 0 and the two tests converge. Treating paired data as independent throws away power.

★Why t and not z?

The standard error uses the sample SD, which is itself an estimate. That extra uncertainty is why the reference distribution is t with df = n − 1 rather than the normal curve:

Raise n and t* shrinks toward z* (they are nearly equal once df passes about 30). With a tiny sample the heavier tails of t keep you from declaring too many false positives; a z test with s in place of σ would not.

4Repeat the experiment many times

Uses the population settings in the sliders (not your own data). If H₀ is true (the true difference is 0, or for the single-sample test the true mean equals μ₀), p-values are uniform and about α of experiments come out “significant” (false positives). If it isn't, the significant share estimates the test's power.

Formulas used

Independent samples. t = (M₁ − M₂) / SE

  • Student: SE = sp·√(1/n₁ + 1/n₂), sp² = [(n₁−1)s₁² + (n₂−1)s₂²]/(n₁+n₂−2), df = n₁ + n₂ − 2
  • Welch: SE = √(s₁²/n₁ + s₂²/n₂), df by Welch–Satterthwaite
  • Effect size: Cohen's d = (M₁ − M₂)/sp; Hedges' g = d·(1 − 3/(4·df − 1)) (with df = n₁ + n₂ − 2)

Repeated measures. Let Di = X1i − X2i. Then t = MD / (sD/√n), df = n − 1, and sD² = s₁² + s₂² − 2·r·s₁·s₂.

  • Effect sizes: dz = MD/sD (difference-score SD) and dav = MD/((s₁+s₂)/2) (comparable to an independent-groups d).

Single sample. t = (M − μ₀) / SE, SE = s/√n, df = n − 1.

  • Effect size: Cohen's d = (M − μ₀)/s; Hedges' g = d·(1 − 3/(4·df − 1)).
  • The CI for μ is M ± tcrit·SE; the CI for M − μ₀ is the same interval shifted down by μ₀. The paired test is exactly this test applied to the difference scores with μ₀ = 0.

Confidence intervals are two-sided at level 1 − α: estimate ± tcrit·SE. p-values come from the exact t distribution (regularised incomplete beta function). Everything runs in your browser; nothing is uploaded.

Key: symbols and terms
H₀
Null hypothesis: the population means do not differ (the true difference is 0). For the single-sample test: the population mean equals μ₀.
Alternative
What you test against H₀. Two-sided: the means differ in either direction. One-sided: the difference goes in one stated direction only.
μ
A population (true) mean. The sliders set the μ values the simulated data are drawn from.
μ₀
The hypothesized population mean that the single-sample test compares the sample mean against (H₀: μ = μ₀). You set it under Test options.
M
A sample mean.
s, s²
Sample standard deviation and variance.
sp
Pooled standard deviation: the two groups' variances combined, weighted by their degrees of freedom.
n
Number of observations (per group, the number of participants in a paired design, or the sample size in a single-sample test).
D, MD, sD
Each participant's difference score (condition 1 − condition 2), its mean, and its standard deviation.
M − μ₀
The single-sample effect: how far the sample mean lies from the hypothesized mean. The t statistic is this distance divided by SE.
r
Pearson correlation between the two conditions across participants. The slider sets the population value; the results show the sample value.
SE
Standard error: the typical size of sampling error in the estimated difference (s/√n for a single sample). Smaller SE gives a larger |t|.
t
Test statistic: the estimated difference divided by its SE, i.e. how many standard errors from 0 it lies.
df
Degrees of freedom: sets the exact shape of the t distribution (heavier tails when df is small). Welch's df is usually not a whole number; single-sample and paired tests use n − 1.
t*
Critical value: the |t| beyond which the result is significant at your α.
p
p-value: the probability of a |t| (or t, if one-sided) at least as extreme as observed if H₀ were true. It is not the probability that H₀ is true.
α
Significance level: the false-positive rate you accept. The result is significant when p < α.
CI
Confidence interval for the true mean difference (for a single sample, the difference between μ and μ₀). At level 1 − α, intervals built this way from repeated samples contain the true value in that proportion of cases.
d, g, dz, dav
Standardised effect sizes: the mean difference in standard-deviation units (for a single sample, d = (M − μ₀)/s). g is d with a small-sample bias correction; dz uses the SD of difference scores; dav uses the average of the two conditions' SDs.
Welch
The independent-samples test that does not assume equal variances; df comes from the Welch–Satterthwaite approximation.
z test
The normal-curve version of the test, correct only if the population SD σ were known. With s estimated from a small sample it gives p-values that are too small.
Type I error
Rejecting H₀ when it is true (a false positive). Its long-run rate equals α when the assumptions hold.
Power
The probability of a significant result when the true difference is not 0. It rises with larger effects, larger n and, for paired data, higher r.
Seed
The number that fixes the random generator, so the same seed reproduces the same simulated sample.
Single-file, dependency-free demo. Simulated data are drawn from normal distributions with a seeded random generator, so a given seed is reproducible.
