Comparison

★Why pairing helps

The paired test works on the difference scores, whose variance shrinks as the correlation between conditions grows:

Raise the correlation r and the paired standard error falls while the independent one stays put. Set r near 0 and the two tests converge. Treating paired data as independent throws away power.

★Why t and not z?

The standard error uses the sample SD, which is itself an estimate. That extra uncertainty is why the reference distribution is t with df = n − 1 rather than the normal curve:

Raise n and t* shrinks toward z* (they are nearly equal once df passes about 30). With a tiny sample the heavier tails of t keep you from declaring too many false positives; a z test with s in place of σ would not.

    Formulas used

    Common to all designs. Every classical test has the form t = (estimate − null value) / SE, compared with a t distribution. Confidence intervals are two-sided at level 1 − α: estimate ± tcrit·SE. p-values come from the exact t distribution (regularised incomplete beta function). Where the designs differ is the estimate, SE and df:

    • Independent samples: estimate M₁ − M₂.
    • Repeated measures: let Di = X1i − X2i; the test is a one-sample test on D with μ₀ = 0, and sD² = s₁² + s₂² − 2·r·s₁·s₂.
    • Single sample: estimate M − μ₀, SE = s/√n, df = n − 1.

    Student’s t. Assumes equal population variances.

    • Independent: SE = sp·√(1/n₁ + 1/n₂), sp² = [(n₁−1)s₁² + (n₂−1)s₂²]/(n₁+n₂−2), df = n₁ + n₂ − 2.
    • Paired and single sample: t = MD / (sD/√n) (or (M − μ₀)/(s/√n)), df = n − 1.
    • Effect size: Cohen’s d = (M₁ − M₂)/sp (single sample d = (M − μ₀)/s); Hedges’ g = d·(1 − 3/(4·df − 1)); for paired data dz = MD/sD and dav = MD/((s₁+s₂)/2).

    Welch’s t. Drops the equal-variance assumption for two independent groups.

    • SE = √(s₁²/n₁ + s₂²/n₂), with Welch–Satterthwaite df = (s₁²/n₁ + s₂²/n₂)² / [(s₁²/n₁)²/(n₁−1) + (s₂²/n₂)²/(n₂−1)].
    • With equal n, Welch’s t equals Student’s t (only df differ). For a single sample or for difference scores there is one variance only, and Welch’s test is Student’s test.

    Yuen’s t (trimmed means). Let γ be the trimming proportion, g = ⌊γn⌋ the number of scores removed from each end and h = n − 2g the number kept.

    • Trimmed mean Mt = mean of the h central scores. Winsorized variance sw² = sample variance after replacing the g lowest scores by the next-lowest kept score and the g highest by the next-highest kept score.
    • Independent (Yuen–Welch): dj = (nj − 1)·sw,j² / (hj(hj − 1)), tY = (Mt1 − Mt2) / √(d₁ + d₂), df = (d₁ + d₂)² / [d₁²/(h₁−1) + d₂²/(h₂−1)].
    • Paired and single sample (Tukey–McLaughlin): tY = (Mt − μ₀) / (sw·√n / h), df = h − 1, applied to the difference scores for paired data (the trimmed mean of the differences, which can differ from the difference of the trimmed means).
    • Robust effect size: dR = c·(Mt1 − Mt2) / sw,pooled (or c·(Mt − μ₀)/sw), where c is the SD of a winsorized standard normal (c ≈ .642 at 20% trimming), so that dR matches Cohen’s d for normal data.
    • With γ = 0, Yuen’s test is Welch’s test (and Student’s test for one set of scores).

    Bayesian t (JZS Bayes factor). Let δ be the standardized effect size (δ = (μ₁ − μ₂)/σ, or (μ − μ₀)/σ). H₀: δ = 0; H₁: δ ~ Cauchy(0, r), with scale r (default √2/2 ≈ 0.71). The data enter only through Student’s t, its df ν and the effective sample size N (N = n₁n₂/(n₁ + n₂) for independent groups, N = n otherwise).

    • BF01 = (1 + t²/ν)−(ν+1)/2 / ∫₀^∞ (1 + N·g·r²)−1/2 (1 + t² / [(1 + N·g·r²)·ν])−(ν+1)/2 (2π)−1/2 g−3/2 e−1/(2g) dg, and BF10 = 1/BF01 (evaluated here by numerical integration).
    • Posterior of δ: prior(δ) × noncentral-t likelihood f(t | ν, λ = δ√N), normalised on a fine grid; the reported median and credible interval come from this posterior.
    • Savage–Dickey check: BF01 = posterior density at δ = 0 / prior density at δ = 0.
    • One-sided hypotheses (δ > 0 or δ < 0) use a half-Cauchy prior: BF+0 = BF10 · P(δ > 0 | data) / P(δ > 0), with P(δ > 0) = ½.
    • Verbal labels (Lee & Wagenmakers): 1–3 anecdotal, 3–10 moderate, 10–30 strong, 30–100 very strong, > 100 extreme; the same bands apply to BF01 for evidence for H₀.

    Key: symbols and terms
    H₀
    Null hypothesis: the population means do not differ (the true difference is 0). For the single-sample test: the population mean equals μ₀. In Bayesian terms: the effect size δ is exactly 0.
    Alternative
    What you test against H₀. Two-sided: the means differ in either direction. One-sided: the difference goes in one stated direction only.
    μ
    A population (true) mean. The sliders set the μ values the simulated data are drawn from.
    μ₀
    The hypothesized population mean that the single-sample test compares the sample mean against (H₀: μ = μ₀). You set it under Test options.
    M
    A sample mean.
    s, s²
    Sample standard deviation and variance.
    sp
    Pooled standard deviation: the two groups’ variances combined, weighted by their degrees of freedom (Student’s test).
    n
    Number of observations (per group, the number of participants in a paired design, or the sample size in a single-sample test).
    D, MD, sD
    Each participant’s difference score (condition 1 − condition 2), its mean, and its standard deviation.
    M − μ₀
    The single-sample effect: how far the sample mean lies from the hypothesized mean.
    r (sample correlation)
    Pearson correlation between the two conditions across participants. The slider sets the population value; the results show the sample value.
    SE
    Standard error: the typical size of sampling error in the estimated difference (s/√n for a single sample). Smaller SE gives a larger |t|.
    t, tY
    Test statistic: the estimated difference divided by its SE, i.e. how many standard errors from 0 it lies. tY is the same idea built from trimmed means.
    df
    Degrees of freedom: sets the exact shape of the t distribution (heavier tails when df is small). Welch’s and Yuen’s df are usually not whole numbers; single-sample and paired Student tests use n − 1.
    t*
    Critical value: the |t| beyond which the result is significant at your α.
    p
    p-value: the probability of a |t| (or t, if one-sided) at least as extreme as observed if H₀ were true. It is not the probability that H₀ is true.
    α
    Significance level: the false-positive rate you accept. The result is significant when p < α. On the Bayesian tab it sets the level (1 − α) of the credible interval.
    CI
    Confidence interval for the true mean difference (for a single sample, the difference between μ and μ₀). At level 1 − α, intervals built this way from repeated samples contain the true value in that proportion of cases.
    d, g, dz, dav
    Standardised effect sizes: the mean difference in standard-deviation units. g is d with a small-sample bias correction; dz uses the SD of difference scores; dav uses the average of the two conditions’ SDs.
    Student’s t
    The classical test that pools the variances (independent groups) and assumes they are equal.
    Welch’s t
    The independent-samples test that does not assume equal variances; df comes from the Welch–Satterthwaite approximation. Equal to Student’s test for one set of scores or for difference scores.
    Yuen’s t
    A robust test of trimmed means (Yuen–Welch for independent groups, Tukey–McLaughlin for one set of scores). It resists outliers and heavy tails.
    Bayesian t
    A test that compares H₀ (δ = 0) with H₁ (δ drawn from a prior) and reports how strongly the data favour each, instead of a p-value.
    γ (trimming proportion)
    Share of the scores removed from each end before computing the trimmed mean. 20% is a common default; 0% gives the ordinary mean.
    g, h
    Number of scores trimmed from each end (g = ⌊γn⌋) and the number kept (h = n − 2g).
    Mt
    Trimmed mean: the mean of the scores that remain after trimming. Hollow dots in the plots are the trimmed scores.
    sw
    Winsorized standard deviation: the SD after the trimmed scores are replaced by the nearest retained score. It is far less affected by outliers than s.
    dR
    Robust effect size: the trimmed-mean difference divided by the winsorized SD and rescaled so that it matches Cohen’s d for normal data.
    Robust
    Little affected by outliers, heavy tails or skew. Robust methods give up a little power under perfectly normal data in exchange for stability when the data are messy.
    Outlier, heavy tails
    An unusually extreme score; a heavy-tailed population produces many of them. They inflate s and can hide a real effect from Student’s test.
    δ
    The standardized effect size in the population (a difference in SD units). The Bayesian analysis reports a probability distribution for δ.
    Prior, posterior
    The prior says which values of δ are plausible before seeing data; the posterior is the updated distribution after seeing the data.
    Cauchy prior, scale r
    A bell-shaped prior with heavy tails centred on 0. The scale r sets its width: a larger r expects larger effects. The default is r = √2/2 ≈ 0.71.
    BF₁₀, BF₀₁
    Bayes factors: how many times more likely the data are under H₁ than under H₀ (BF₁₀), or the reverse (BF₀₁ = 1/BF₁₀). BF₁₀ = 5 means the data are five times more likely under H₁. BF₊₀ and BF₋₀ are the one-sided versions.
    Credible interval
    The interval that contains δ with the stated posterior probability (e.g. 95%), given the data and the prior. It is a direct probability statement, unlike a confidence interval.
    Effective n
    The sample size that enters the Bayes factor: n₁n₂/(n₁ + n₂) for two independent groups, n otherwise.
    Savage–Dickey ratio
    The posterior density at δ = 0 divided by the prior density at δ = 0; it equals BF₀₁.
    Lindley’s paradox
    With a large sample, a result can be significant (p < α) while the Bayes factor favours H₀, because a tiny effect fits a modest t poorly.
    z test
    The normal-curve version of the test, correct only if the population SD σ were known. With s estimated from a small sample it gives p-values that are too small.
    Type I error
    Rejecting H₀ when it is true (a false positive). Its long-run rate equals α when the assumptions hold.
    Power
    The probability of a significant result when the true difference is not 0. It rises with larger effects, larger n and, for paired data, higher r.
    Seed
    The number that fixes the random generator, so the same seed reproduces the same simulated sample.
