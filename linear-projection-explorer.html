Linear Projection Explorer

See how two methods rotate multivariate data onto new axes. PCA finds the directions of greatest variance; ICA unmixes hidden, independent sources that were added together.

Method guide

MethodHow it worksReach for it when…Watch out for…
Principal Component AnalysisRotates the axes to the directions of greatest variance, giving uncorrelated components ranked by variance explained.You want to compress many correlated variables or see them in two dimensions.Linear only; sensitive to units (standardize!); high variance does not always mean important.
Independent Component AnalysisFinds directions that make the components as statistically independent (as non-Gaussian) as possible, after whitening.Unmixing signals that were added together (cocktail party, EEG artifacts).Needs non-Gaussian sources and a linear mixture; order, sign and scale of components are arbitrary.

Projection

Eigenvalue
Variance captured by a principal component.
Loading
Weight of an original variable in a component. Large magnitude means that variable matters to that component.
Score
A case’s coordinate on a component.
Scree plot
Bar chart of eigenvalues; look for the elbow where bars level off.
Standardize
Rescale each variable to unit variance first (PCA on the correlation matrix) so large-unit variables do not dominate.
Whitening
Rotating and scaling data so the variables are uncorrelated with unit variance. ICA’s first step.
Excess kurtosis
Non-Gaussianity: 0 for a Gaussian, negative for flat (uniform) data, positive for spiky data.
Recovery score
Average absolute correlation between each recovered component and the best-matching true source (1 is perfect). Sign and order are ignored because they are arbitrary.
All data are simulated in your browser; nothing is uploaded.
